02 / Rule register

Four signals. One readable record.

The analyzer stays deliberately narrow. Each result points to a concrete Compose field, keeps its evidence close, and avoids turning configuration into a claim about a running system.

  1. 01
    PRIVILEGED_CONTAINER

    Privileged container mode

    Flags a service using privileged: true, a direct elevation of the container context.

    field / privilegedseverity / high
  2. 02
    WRITABLE_HOST_BIND

    Writable host bind

    Identifies a local host directory mounted into a service with write access, exposing shared data to that container.

    field / volumesseverity / medium
  3. 03
    DANGEROUS_CAPABILITY

    Dangerous capability

    Checks explicit additions such as ALL, NET_ADMIN, SYS_ADMIN, and SYS_PTRACE.

    field / cap_addseverity / high
  4. 04
    EXPOSED_SERVICE_PORT

    Published service port

    Reports an explicit host-published port while leaving reachability, routing, and runtime state outside the finding.

    field / portsseverity / medium
03 / Correlation

A bounded path, not a story.

Two findings on the same service can be joined into one precise explanation. The analyzer does not invent a graph beyond that deterministic relationship.

Single attack-path correlation

When privileged mode and a writable host bind meet on one service, the evidence points from elevated context to shared data. It is static analysis, not exploit execution.

04 / Boundary + claims

The boundary is part of the result.

SynapseAudit reports what is present in a Compose file and keeps the unknowns visible. Configuration-only limitations are not buried in a footnote.

01

Reads configuration locally. Safe parsing evaluates Compose YAML; it does not scan the runtime environment.

02

No services started. No images, commands, containers, or Docker operations are executed during review.

03

Local-only state. The review makes no external calls and uses no Docker socket.

04

Configuration-only claims. Findings do not prove internet reachability, firewall exposure, routing, proxy access, service health, or exploit execution.
